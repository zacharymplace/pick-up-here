# RC.7 workflow demo

[Watch or download the captioned MP4](https://raw.githubusercontent.com/zacharymplace/pick-up-here/main/demo/rc7-demo-captioned.mp4).

This 28.32-second recording shows real local Gemma inference on a synthetic
Workshop repository, saving/reopening a brief, fresh comparison after a harness
README edit, exporting both evidence packets, and historical reopening with
integrity checking and recomputation. No private repository exports are included.

The captioned edit removes 33.5 seconds of real inference waiting and labels
the cut. The actual call took approximately 40 seconds on the shared host.
The original 61.84-second recording is retained in the release preparation
package. This is a supplementary demo, not a productivity benchmark.
